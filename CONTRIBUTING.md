# Contributing to LibreELEC Hades

## Problems and questions

Report problems with LibreELEC Hades in the issues of this repository, with the bug report form. It asks for what is needed to find a problem: the build, the graphics and the TV, what was played, and a log (see [Reporting problems](README.md#reporting-problems) in the README). A question or an idea can go in a blank issue. Please write in English if you can; a machine translation is fine.

Do not report problems with this build to LibreELEC, Kodi, Dolby, NVIDIA, AMD or Intel: they do not make it and cannot help with it. If the same problem also happens with an official LibreELEC image, it belongs to LibreELEC or Kodi and can be reported there.

## Suggesting changes

The best way to suggest a change is an issue that says what it is and why, so that it can be talked over first.

## Documentation

If a page of the documentation is hard to follow, or a setting is not explained well, that is a fault in the documentation: say which page and what you could not tell, in an issue.

## LibreELEC's guides

The tree follows LibreELEC's coding standards, [STANDARDS.md](STANDARDS.md), and its guide to the package recipes, [packages/README.md](packages/README.md). LibreELEC's own guide to contributing, which is about LibreELEC and not about this build, is kept as it is in [CONTRIBUTING.LibreELEC.md](CONTRIBUTING.LibreELEC.md).
