# Contributing to LibreELEC Hades

## Problems and questions

Report problems with LibreELEC Hades in the issues of this repository, with the bug report form: it asks for what is needed to find a problem (the build, the graphics and the TV, what was played, and a log). "Reporting problems" in the [README](README.md#reporting-problems) says the same. A question or an idea can go in a blank issue.

Do not report problems with this build to LibreELEC, Kodi, Dolby, NVIDIA, AMD or Intel: they do not make it and cannot help with it. If the same problem also happens with an official LibreELEC image, it belongs to LibreELEC or Kodi and can be reported there, against their image.

## Suggesting changes

The best way to suggest a change is an issue that says what it is and why, so that it can be talked over first.

## LibreELEC's guides

The tree follows LibreELEC's coding standards, [STANDARDS.md](STANDARDS.md), and its guide to the package recipes, [packages/README.md](packages/README.md). LibreELEC's own guide to contributing, which is about LibreELEC and not about this build, is kept as it is in [CONTRIBUTING.LibreELEC.md](CONTRIBUTING.LibreELEC.md).

## En español

Cómo avisar de un problema: «Avisar de problemas» en [README.es.md](README.es.md#avisar-de-problemas). Puedes escribir en inglés o en español. Para sugerir un cambio, lo mejor es abrir un issue que diga qué es y por qué.
