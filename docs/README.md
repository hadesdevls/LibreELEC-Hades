# Documentation

More detail than the [README](../README.md) gives, for those who want to know how LibreELEC Hades works, what each of its settings does, or what to send with a report. In English; the README is also [in Spanish](../README.es.md).

- [How the Dolby Vision output works](how-it-works.md): the path of a frame from the file to the HDMI cable, when native Dolby Vision is used, Dolby Vision shown as HDR10 or sent as Low-Latency, HDR10+, a display without HDR, [stereoscopic 3D](how-it-works.md#stereoscopic-3d), and the backend of each graphics driver.
- [Settings](settings.md): every setting this build adds, where it is, its default and when to change it.
- [Bluetooth](bluetooth.md): why a Bluetooth device disconnected, a device used in Windows and in LibreELEC Hades on one PC, Intel controllers after a restart from Windows, and USB power saving.
- [Diagnostics and logs](diagnostics.md): the diagnostic switch, how to get the diagnostics and the log off the PC, what the filter takes out, and the lines of `kodi.log` that tell most.

What has been tested, the known limits, the defaults that differ from LibreELEC, how to install, update and build, and the credits are in the [README](../README.md).
